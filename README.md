One word, and nothing else: the single word a grandma would text about AI. `main.py` writes that word to `/output/entry.txt`. The word is "robut" — the way a grandma types "robot" on her phone: one letter slipped, warm, a little baffled, funny on its own, and unmistakably about a machine.

## Run it

```sh
python3 main.py
```

It writes `robut` (5 bytes, one word, no newline) to `/output/entry.txt`.
